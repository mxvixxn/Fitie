# Fitie v1.1 — 기능 확장 설계 (Design Spec)

- **날짜:** 2026-07-05
- **전제:** v1 코어 + 애플 순정 리디자인 완료 상태에서 출발
- **상태:** 제안 — 사용자 리뷰 대기

---

## 배경: 지금 어디에 있나

v1은 "HealthKit이 알아서 채워주는 정직한 습관 트래커 + 컨디션 인사이트"라는
코어 루프를 구현했다. 코드를 조사한 결과, **설계는 되어 있는데 미완성인 지점**과
**매일 쓰기에 부족한 지점**이 명확하다:

| 발견 | 근거 |
|---|---|
| 하루가 끝나도 판정이 확정되지 않음 | `RefreshService.refreshToday`가 항상 `dayIsOver: false` → 미달한 날이 영원히 `pending`, 스트릭·히트맵이 부정확 |
| 요일 스케줄이 모델에만 존재 | `Habit.activeWeekdays` + `isActive(on:)`은 구현·사용되나, 편집 시트에 UI가 없고 오늘 탭이 필터하지 않음 |
| HealthKit 지표 5종 외 습관 불가 | 독서·영양제·공부 같은 흔한 습관을 만들 수 없음. 스펙의 "수동 체크 폴백" 개념(`ResultSource.manual`)은 모델에만 존재 |
| 알림이 무조건 울림 | 이미 달성한 습관도 리마인더 발송. 컨디션 체크인(인사이트의 원료) 리마인더는 아예 없음 |
| 과거 기록을 볼 수 없음 | 오늘 + 습관별 35일 히트맵뿐. 지난 날짜의 결과·컨디션 열람/수정 불가 |
| 인사이트 탭의 "습관별 달성률" 미구현 | v1 스펙 화면 목록에 있었으나 빠짐 |

## 검토한 방향 3가지

- **(A) 코어 루프 완성 + 리텐션** ← **채택**
  - 위 표의 갭을 메워 "매일 쓰는 앱"으로 완성. 유료 계정 불필요, 전부 시뮬레이터 검증 가능.
- **(B) AI/인사이트 심화** (상관 차트 고도화, 주간 리포트 생성 등)
  - 데이터가 쌓여야 빛나는 기능. 판정 확정(A-1)조차 안 된 상태에서는 인사이트 원료가 부정확 → A 이후가 순서.
- **(C) 플랫폼 확장** (홈 위젯, Watch, 푸시 Live Activity)
  - App Groups·원격 푸시가 유료 Apple Developer Program 필요 → v1 스펙의 제약이 그대로 유효. v2 유지.

## v1.1 범위 (우선순위순)

### P1 — 정직한 트래커 완성

1. **하루 마감 판정 (Day Finalization)**
   - 새 날의 첫 새로고침 때, 마지막 확정일 다음 날부터 어제까지를 `dayIsOver: true`로 재평가해
     `pending/inProgress → achieved/missed` 확정. `RefreshService.refresh(day:dayIsOver:)`로 일반화.
   - 수동 체크 결과(`source == .manual`)는 자동 판정이 덮어쓰지 않는다.
2. **수동 체크 습관** (`HealthMetric.manual`)
   - 목표 1, 측정값 1로 기존 `HabitEvaluator`를 그대로 통과 → 로직 추가 없이 상태 3종 일관.
   - 오늘 탭 행에서 탭으로 체크/해제. 새로고침은 수동 습관을 건너뛰고, 마감 판정 때만 미체크 → `missed`.
3. **요일 스케줄 UI 연결**
   - 편집 시트에 요일 선택(일–토 토글), 오늘 탭은 `habit.isActive(on: today)`만 표시.
   - `RefreshService`는 이미 `isActive` 필터 중 — UI만 잇는다.

### P2 — 매일 열게 만드는 리텐션

4. **스마트 리마인더**
   - 습관 리마인더를 반복 트리거 → **향후 7일 개별 예약**으로 교체. 새로고침 때 재무장(re-arm)하며
     "오늘 이미 달성"이면 오늘 것만 건너뜀.
   - **컨디션 체크인 리마인더** 신설(설정에서 on/off + 시각, 기본 21:30, 반복 트리거).
5. **기록 캘린더 (History)**
   - 오늘 탭 툴바에 캘린더 버튼 → 월 그리드 시트. 날짜 탭 → 그날 습관 결과 + 컨디션 열람,
     컨디션은 기존 `ConditionCheckInSheet(day:existing:)` 재사용으로 과거 입력/수정 가능.
6. **인사이트: 습관별 달성률 카드**
   - 최근 30일 습관별 달성률 리스트(아이콘 + 게이지 + %). v1 스펙 잔여 항목 이행.

### P3 — 완성도 (여유 시)

7. **습관 프리셋 퀵 추가** — 새 습관 시트 상단 추천 칩(걷기 6000보, 물 8잔, 운동 20분, 마음챙김 10분, 23시 취침, 독서(수동)).
8. **데이터 내보내기** — 설정에서 전체 기록 JSON 공유(ShareLink). 로컬-온리 앱의 백업 스토리.

## 비범위 (변경 없음)

소셜/계정/클라우드 없음 · 의학적 조언 없음 · 위젯/Watch는 유료 계정 가입 후 v2.

## 데이터 모델 영향

- 스키마 변경 **없음** (P1–P3 전부). `HealthMetric.manual`은 Codable enum 케이스 추가라
  기존 저장 데이터와 호환. 마지막 확정일은 `UserDefaults`(`lastFinalizedDay`).
- 마이그레이션 불필요 — 리스크 최소.

## 에러 처리 원칙 (v1 계승)

- HealthKit 조회 실패한 과거 날짜는 확정하지 않고 다음 새로고침에 재시도.
- 알림 권한 거부 시 예약 시도만 하고 조용히 무시(UI 차단 없음).
- 수동 습관은 HealthKit·권한과 완전 무관하게 동작.

## 테스트 전략

- 순수 로직(TDD): 마감 판정 경계(어제 미달→missed, 수동 보호, 여러 날 누락), 수동 습관 평가,
  요일 활성 필터, 달성률 집계.
- UI: 빌드 + `simctl` 스크린샷(FITIE_SEED)으로 화면 검증 — v1과 동일한 루프.
